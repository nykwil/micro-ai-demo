# Micro-AI Demo

A Three.js + Vite demonstration of simple steering behaviors.

## Behaviors
- **Seek:** Agents move directly towards the target (Red Sphere).
- **Flee:** Agents move directly away from the target.
- **Wander:** Agents move smoothly in random directions.
- **Orbit:** Agents circle around the target.

## Controls
- **Double Click:** Teleport the target (Red Sphere) to the mouse position on the ground plane.
- **UI Buttons:** Switch the active behavior for all agents.

## Setup & Run
1. `npm install` (if not done)
2. `npm run dev`
3. Open the link (usually http://localhost:5173)
